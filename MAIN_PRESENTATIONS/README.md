## 🎯 Day 1 Spotlight: Syllabus Scope & 22-Item Coverage Checklist

As established from the official PDF curriculum, Day 1 contains **strictly 7 topics**:

```markdown
### 1. Introduction to HPC
- [ ] 01. HPC concept and purpose
- [ ] 02. HPC system overview
- [ ] 03. HPC versus ordinary computing

### 2. Intel HPC Architecture
- [ ] 04. Intel Xeon
- [ ] 05. GPUs
- [ ] 06. AI accelerators
- [ ] 07. Hardware roles

### 3. Linux Basics
- [ ] 08. Filesystem and paths
- [ ] 09. Basic commands
- [ ] 10. Environment setup

### 4. Shell Scripting
- [ ] 11. Script creation and execution
- [ ] 12. Variables and commands
- [ ] 13. Task automation

### 5. SSH
- [ ] 14. Remote access
- [ ] 15. Connection syntax
- [ ] 16. Authentication basics

### 6. Intel oneAPI Toolkit
- [ ] 17. Toolkit purpose
- [ ] 18. Components overview
- [ ] 19. Environment access

### 7. Intel HPC Toolkit
- [ ] 20. Toolkit introduction
- [ ] 21. HPC workflow
- [ ] 22. Available tools
```

> **Syllabus Boundary Note:** OpenMP, MPI, ML, TensorFlow, Slurm, Horovod, VTune, and LLM training are strictly kept on Days 2 to 5 to protect student comprehension.
