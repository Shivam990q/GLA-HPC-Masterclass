### BCSG_D5_01: In Python regular expressions, which metacharacter matches ONE OR MORE occurrences of the preceding character or pattern?

- A) *
- B) +
- C) ?
- D) ^

**Correct Answer**: B

**Detailed Technical Explanation**:
> `+` matches 1 or more occurrences. `*` matches 0 or more occurrences. `?` matches 0 or 1 occurrence.

---

### BCSG_D5_02: Which character class in regular expressions matches any single digit from 0 to 9 (equivalent to `[0-9]`)?

- A) \w
- B) \s
- C) \d
- D) \b

**Correct Answer**: C

**Detailed Technical Explanation**:
> `\d` matches any decimal digit. `\w` matches word characters (alphanumeric + underscore), and `\s` matches whitespace.

---

### BCSG_D5_03: Which function from the `re` module replaces occurrences of a pattern with a replacement string?

- A) re.replace()
- B) re.sub()
- C) re.swap()
- D) re.change()

**Correct Answer**: B

**Detailed Technical Explanation**:
> `re.sub(pattern, replacement, string)` substitutes occurrences of `pattern` with `replacement` in `string`.

### BCSG_D5_04: In Python's `sqlite3` module, why should query parameters ALWAYS be passed using `?` placeholders instead of string formatting (`f'...'`)?

- A) String formatting is deprecated in Python.
- B) To protect against SQL Injection vulnerabilities by having the database engine treat inputs strictly as literal values.
- C) It improves disk space usage.
- D) SQLite does not support strings.

**Correct Answer**: B

**Detailed Technical Explanation**:
> Parameterized queries (`cursor.execute('SELECT * FROM users WHERE name = ?', (name,))`) ensure user inputs are sanitized and never executed as SQL code.

### BCSG_D5_05: Which method on a `sqlite3` cursor retrieves ALL remaining rows from a query result set as a list of tuples?

- A) cursor.get_rows()
- B) cursor.fetchall()
- C) cursor.read_all()
- D) cursor.fetchmany()

**Correct Answer**: B

**Detailed Technical Explanation**:
> `cursor.fetchall()` fetches all rows of a query result as a list of tuples. `fetchone()` fetches a single row.
