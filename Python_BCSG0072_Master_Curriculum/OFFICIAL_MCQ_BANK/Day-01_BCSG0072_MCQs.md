### BCSG_D1_01: In Python, which construct executes its block ONLY if a loop finishes without hitting a `break` statement?

- A) loop-finally
- B) loop-else
- C) loop-default
- D) loop-catch

**Correct Answer**: B

**Detailed Technical Explanation**:
> Python's `for-else` and `while-else` construct executes the `else` block only if the loop terminates normally without encountering a `break` statement.

### BCSG_D1_02: What is the time complexity of appending an element to the end of a Python list (`list.append(x)`)?

- A) O(N)
- B) O(log N)
- C) O(1) amortized
- D) O(N^2)

**Correct Answer**: C

**Detailed Technical Explanation**:
> Python lists are dynamic arrays with over-allocation, making append an $O(1)$ amortized operation.

### BCSG_D1_03: Which string method removes whitespace characters from BOTH the left and right ends of a string?

- A) clean()
- B) trim()
- C) strip()
- D) rstrip()

**Correct Answer**: C

**Detailed Technical Explanation**:
> `str.strip()` removes leading and trailing whitespace. `lstrip` removes left-only, and `rstrip` removes right-only.

### BCSG_D1_04: What does the slice expression `s[::-1]` evaluate to when applied to a string `s`?

- A) Returns every alternate character.
- B) Reverses the string.
- C) Returns the first and last character.
- D) Raises a ValueError.

**Correct Answer**: B

**Detailed Technical Explanation**:
> A step of `-1` without start/stop indices reverses the sequence.

### BCSG_D1_05: Which of the following data types in Python is MUTABLE?

- A) int
- B) tuple
- C) str
- D) list

**Correct Answer**: D

**Detailed Technical Explanation**:
> `list`, `dict`, and `set` are mutable. `int`, `float`, `str`, and `tuple` are immutable.
