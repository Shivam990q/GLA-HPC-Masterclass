### BCSG_D4_01: In a Python `try-except-else-finally` block, when does the `else` clause execute?

- A) Only when an exception is raised and handled.
- B) Only when the `try` block completes successfully WITHOUT raising any exceptions.
- C) Always, regardless of exceptions.
- D) Only if `finally` fails.

**Correct Answer**: B

**Detailed Technical Explanation**:
> The `else` block executes only if the code in the `try` block executed cleanly without triggering any exceptions.

### BCSG_D4_02: What is the primary benefit of using the `with open(...) as f:` context manager when working with files?

- A) It accelerates file reading speed by 10x.
- B) It guarantees that the file handle is automatically closed when execution exits the block, even if an exception occurs.
- C) It encrypts the file on disk.
- D) It deletes the file upon exit.

**Correct Answer**: B

**Detailed Technical Explanation**:
> The `with` statement calls `__enter__()` and guarantees `__exit__()`, closing the file descriptor deterministically to prevent resource leaks.

### BCSG_D4_03: Which file open mode should be used to append new data to the end of an existing file without overwriting its contents?

- A) 'r'
- B) 'w'
- C) 'a'
- D) 'r+'

**Correct Answer**: C

**Detailed Technical Explanation**:
> Mode `'a'` (append) opens the file for writing and places the file pointer at the end of the file. If the file does not exist, it creates it.

### BCSG_D4_04: What does the file method `f.tell()` return?

- A) The total line count of the file.
- B) The current byte position/offset of the file pointer.
- C) The file name.
- D) The file size in megabytes.

**Correct Answer**: B

**Detailed Technical Explanation**:
> `f.tell()` returns an integer representing the current byte position of the file pointer within the file stream.

### BCSG_D4_05: How do you create a User-Defined Custom Exception in Python?

- A) By defining a function with @exception decorator.
- B) By creating a class that inherits from the built-in `Exception` class.
- C) By writing a lambda expression.
- D) By calling sys.exit().

**Correct Answer**: B

**Detailed Technical Explanation**:
> Custom exceptions are created by subclassing `Exception` (or a subclass of it): `class MyError(Exception): pass`.
