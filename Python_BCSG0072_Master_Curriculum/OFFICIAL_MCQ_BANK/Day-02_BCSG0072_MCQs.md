### BCSG_D2_01: What is the key difference between a Python tuple and a list?

- A) Tuples are mutable, lists are immutable.
- B) Tuples are immutable, lists are mutable.
- C) Tuples cannot store strings.
- D) Lists cannot store mixed data types.

**Correct Answer**: B

**Detailed Technical Explanation**:
> Tuples cannot be modified after creation (immutable), while lists can be updated in-place (mutable).

### BCSG_D2_02: Which set method removes an element from a set WITHOUT raising a KeyError if the element does not exist?

- A) remove()
- B) discard()
- C) pop()
- D) delete()

**Correct Answer**: B

**Detailed Technical Explanation**:
> `set.discard(x)` safely removes element `x` without raising an error if it is missing, whereas `set.remove(x)` raises a `KeyError`.

### BCSG_D2_03: In Python dictionary operations, why is `dict.get(key, default)` preferred over direct bracket indexing `dict[key]`?

- A) It executes 10x faster.
- B) It returns the default fallback value instead of raising a KeyError if the key is absent.
- C) It sorts the dictionary.
- D) It locks the dictionary.

**Correct Answer**: B

**Detailed Technical Explanation**:
> Direct indexing `d[key]` raises `KeyError` if the key does not exist. `d.get(key, default)` gracefully returns `default` (or `None`).

### BCSG_D2_04: In Python scope resolution, what does the LEGB acronym stand for?

- A) Linear, External, Global, Binary
- B) Local, Enclosing, Global, Built-in
- C) Logical, Environmental, Generic, Base
- D) Local, Explicit, Global, Bound

**Correct Answer**: B

**Detailed Technical Explanation**:
> Python searches variable identifiers in the order: Local -> Enclosing (nested functions) -> Global (module level) -> Built-in.

### BCSG_D2_05: Which built-in functional tool applies an accumulator function cumulatively to items of an iterable to reduce it to a single value?

- A) map()
- B) filter()
- C) functools.reduce()
- D) zip()

**Correct Answer**: C

**Detailed Technical Explanation**:
> `functools.reduce(func, iterable)` repeatedly applies a binary function to reduce the iterable to a single scalar value.
