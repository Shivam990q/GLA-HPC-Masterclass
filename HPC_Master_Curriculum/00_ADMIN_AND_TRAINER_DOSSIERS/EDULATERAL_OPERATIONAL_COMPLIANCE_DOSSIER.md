## 💾 Section 5: The Offline Pen Drive Software Dump Kit (Clause 3)

### 5.1 The Pen Drive Directive
* **The Mandate**: *"Have dumps of all softwares required in pen drive and everybody has the presentation and necessary documents handy."*
* **Operational Vulnerability Addressed**:
  - University computer labs frequently experience network throttling, aggressive proxy firewalls, blocked PyPI/Conda ports, or complete internet outages.
  - If 60 students simultaneously attempt `pip install tensorflow` or `git clone` during a lab, the lab network collapses, bringing the training to a catastrophic standstill.
* **The Solution**:
  - Pre-configure a master bootable/high-speed USB 3.2 pen drive (and distribute copies across lab PCs) containing:
    1. Complete offline Python wheel repository (`wheels/`) covering NumPy, Pandas, Scikit-learn, `scikit-learn-intelex`, TensorFlow-MKL, OpenVINO, `optimum-intel`, Horovod, and mpi4py.
    2. Miniconda3 standalone Linux x86_64 installer script.
    3. Standalone Intel oneAPI Base Toolkit and HPC Toolkit offline installers (`l_BaseKit_*_offline.sh`, `l_HPCKit_*_offline.sh`).
    4. Slurm simulator scripts and standalone OpenMPI tarballs.
    5. Synthetic offline CSV and NPZ benchmark datasets (100,000 to 5,000,000 rows).
    6. All 5 Edulateral branded PowerPoint presentation decks (`.pptx`) and PDF equivalents.
    7. Fully automated 1-click lab setup bash script `setup_offline_lab.sh`.
