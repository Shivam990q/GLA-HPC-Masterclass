### D3_Q01: What is the architectural difference between WSGI (Flask) and ASGI (FastAPI)?

- A) WSGI supports WebSockets while ASGI only supports HTTP.
- B) WSGI handles requests synchronously with dedicated worker threads, whereas ASGI is built on asynchronous event loops (`asyncio`) supporting non-blocking concurrent I/O.
- C) WSGI is compiled in C++, while ASGI is interpreted.
- D) WSGI requires Docker, while ASGI does not.

**Correct Answer**: B

**Detailed Technical Explanation**:
> ASGI (Asynchronous Server Gateway Interface) enables Python web applications to handle thousands of concurrent requests by leveraging non-blocking asynchronous event loops (`asyncio`), whereas WSGI is synchronous.

### D3_Q02: Which library does FastAPI utilize under the hood for data validation, schema enforcement, and serialization?

- A) Marshmallow
- B) Cerberus
- C) Pydantic
- D) SchemaPy

**Correct Answer**: C

**Detailed Technical Explanation**:
> FastAPI is built tightly around Pydantic. Pydantic v2 is compiled in Rust, providing ultra-fast data validation and automatic conversion between Python types and JSON.

### D3_Q03: What are the three components of a JSON Web Token (JWT) separated by periods?

- A) Username, Password, Timestamp
- B) Header, Payload, Signature
- C) ClientID, ClientSecret, Scope
- D) Cipher, Key, Salt

**Correct Answer**: B

**Detailed Technical Explanation**:
> A JWT consists of three base64-encoded segments: `Header` (algorithm & token type), `Payload` (claims/user data), and `Signature` (cryptographic verification hash).

### D3_Q04: Which protocol provides full-duplex, persistent two-way communication over a single TCP connection, eliminating HTTP polling overhead?

- A) HTTP/1.1
- B) gRPC Unary
- C) WebSocket (`ws://`)
- D) FTP

**Correct Answer**: C

**Detailed Technical Explanation**:
> WebSockets establish a persistent full-duplex TCP channel between client and server, allowing bidirectional messaging with minimal framing overhead.

### D3_Q05: Which interactive API documentation interfaces are automatically generated by FastAPI out-of-the-box?

- A) Postman collection and cURL scripts
- B) Swagger UI (at `/docs`) and ReDoc (at `/redoc`)
- C) GraphQL playground only
- D) WSDL XML schemas

**Correct Answer**: B

**Detailed Technical Explanation**:
> FastAPI inspects route definitions and Pydantic models to automatically serve OpenAPI-compliant interactive documentation at `/docs` (Swagger UI) and `/redoc` (ReDoc).
