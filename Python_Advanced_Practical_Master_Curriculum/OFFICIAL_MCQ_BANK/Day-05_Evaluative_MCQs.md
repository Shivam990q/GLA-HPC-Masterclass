### D5_Q01: In Conversational AI and customer support bots, what is the primary role of Intent Recognition?

- A) To translate text from English to Hindi.
- B) To classify the user's natural language utterance into a predefined action or topic category.
- C) To extract numbers and dates from strings.
- D) To generate voice audio waveforms.

**Correct Answer**: B

**Detailed Technical Explanation**:
> Intent Recognition is a text classification task that determines the overarching goal or request of the user (e.g. `check_order_status`, `refund_request`, `hours_of_operation`).

### D5_Q02: Which mathematical metric measures the orientation between two TF-IDF text feature vectors to quantify semantic document similarity?

- A) Euclidean distance
- B) Manhattan distance
- C) Cosine Similarity
- D) Hamming distance

**Correct Answer**: C

**Detailed Technical Explanation**:
> Cosine Similarity measures the cosine of the angle between two multi-dimensional feature vectors: $\cos(\theta) = \frac{A \cdot B}{\|A\| \|B\|}$. It evaluates orientation rather than vector length, making it ideal for text comparison.

### D5_Q03: What is the purpose of setting a Confidence Threshold in an automated NLP chatbot?

- A) To speed up token generation on GPUs.
- B) To prevent the chatbot from providing hallucinations or incorrect answers by routing low-confidence matches to a fallback response or human agent.
- C) To encrypt user chats.
- D) To limit user character length.

**Correct Answer**: B

**Detailed Technical Explanation**:
> A Confidence Threshold ensures that if the highest intent similarity score falls below a minimum reliability boundary (e.g. 0.30), the system gracefully triggers a fallback message rather than guessing incorrectly.

### D5_Q04: How can an AI classification model trigger automated workflows (such as sending high-priority alerts or creating support tickets)?

- A) By printing the output to the console.
- B) By inspecting model prediction probability thresholds and executing webhook callbacks or event queue dispatches.
- C) By recompiling the Python script.
- D) By restarting the server.

**Correct Answer**: B

**Detailed Technical Explanation**:
> AI automation pipelines evaluate model prediction outputs (e.g. if `prob >= 0.90` and `label == 'fraud'`) and programmatically trigger event-driven webhooks, SMS alerts, or database writes.

### D5_Q05: Which Python web server is standard for deploying asynchronous FastAPI applications across multiple worker processes in production?

- A) Apache HTTP Server
- B) Uvicorn with Gunicorn worker management
- C) Python SimpleHTTPServer
- D) IIS

**Correct Answer**: B

**Detailed Technical Explanation**:
> Uvicorn (a lightning-fast ASGI server) managed by Gunicorn process managers (`gunicorn -w 4 -k uvicorn.workers.UvicornWorker main:app`) is the production industry standard for running FastAPI applications.
